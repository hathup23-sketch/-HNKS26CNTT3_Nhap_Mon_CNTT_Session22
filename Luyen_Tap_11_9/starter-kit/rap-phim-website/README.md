


# CineBox – Đặt vé xem phim mini

Website **đặt vé** *xem phim mini*
## Cấu trúc thư mục

| Thư mục | Nội dung | Chú Thích |
|---|---|---|
| docs | Tài liệu dự án | Chứa tài liệu |
| data | Dữ liệu đặt vé | Chứa file Excel |
| logs | Nhật ký hệ thống | Chứa file log |

## Lệnh liệt kê dự án

```powershell
Get-ChildItem -Force -Recurse
```
